# evolutions/ — 对比与采纳记录

本目录保存 skill-creator 的**反馈闭环**记录，分两类：

| 类型 | 文件名 | 场景 | 真实示例 |
|---|---|---|---|
| 择优对比 | `<YYYY-MM-DD>-compare-<技能名>.md` | 自建技能 vs 上游候选对比择优 | `2026-09-02-compare-pr-summarizer.md` |
| 上游导入 | `<YYYY-MM-DD>-import-<技能名>.md` | 本地无候选（A 空），按用户指定直接导入上游并适配 | `2026-09-03-import-code-review-skill.md` |
| 采纳升级 | `<YYYY-MM-DD>-adopt-<主题>.md` | 采纳上游的纪律/工具/方法论的升级记录 | `2026-09-10-adopt-agent-review-loop.md` |

## 记录规范

### 择优对比（compare-）文件名与模板

```
<YYYY-MM-DD>-compare-<技能名>.md
示例：2026-09-02-compare-pr-summarizer.md（真实记录）
```

### 记录内容模板

```markdown
# 对比记录：<自建技能名> vs 上游 <候选技能名>

## 基本信息
- 日期：
- 需求描述：
- 上游候选来源：索引 path（如 skills/xxx）

## 对比报告
（贴入 compare_skills.py 的输出，或摘要各维度分数）

## 结论
- 优者：上游 / 自建 / 持平
- 采纳决定：

## 差异分析（仅上游更优时需要）
- 上游优势维度及具体做法（章节组织/门控/资源结构）
- 自建差距原因

## 提炼的学习点
- 学习点 1：…（可直接用于改进 skill-creator）
- 学习点 2：…

## 改进建议（可选）
- 建议更新 skill-creator SKILL.md / references 的哪些部分
```

### 上游导入（import-）记录要点

本地无候选时的「直接导入 + 适配」记录（模板可参考择优对比），要点：本地 A 空证据（检索 0 命中）→ 上游来源与许可 → 采纳形态（整目录 / 方法论吸收等）→ 适配要点（frontmatter/schema 补齐、章节补全）→ 验证与审计位置。

### 采纳升级（adopt-）记录要点

非「技能 vs 候选」的方法论/工具升级（吸收上游写作规范、把纪律落地为脚本等）用此类型，记录：需求与证据 → 上游来源 → 采纳要点（改了什么、对齐到哪）→ 版本 bump → 验证结果 → 学习点。标题示例：`# 纪律→工具：…` / `# 吸收上游 …`。

### 后续处理

- 每季度（或积累 5-10 条记录时）review 本目录，汇总「学习点」→ 迭代 skill-creator。
- review 后可把已采纳的学习点移入 `references/`（作为方法论沉淀），本记录作为历史留存。
