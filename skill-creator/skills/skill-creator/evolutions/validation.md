# 校验与安全扫描：合并审计结论

覆盖 2026-09-10—09-29。多轮“发现→修复→复查”合并为仍需保留的边界与回归依据；逐轮版本和完整补丁可按旧记录映射查 Git。

<a id="contracts"></a>
## 数据与文件契约

- 校验外部技能时仅在目标技能自身解析引用，禁止回退到创建器资源而假通过。扫描零个技能或错误目录必须失败。
- name 为小写 kebab-case、≤100 字符并与目录一致；description 空白和超长在创建前拒绝。引用/YAML 转义采用安全替换，BOM、多行、引号、非 ASCII 与反斜杠须往返一致。
- evals 缺失为 advisory；存在时强制 query/prompt、布尔 should_trigger 和整体形状。advisory 不等于 strict 的 warning/error。
- 章节识别与解析共享；offensive 技能的授权免责声明按语义组成容错匹配。frontmatter 旧 tools/tags/version/来源必需检查已于 09-11 瘦身撤销，不能从早期审计重新引入。
- Markdown 引用处理链接标题、围栏豁免和常见资源扩展名。引用豁免仅接受闭合围栏；安全扫描将未闭合围栏延到 EOF，二者视图有意不同。
- 非文件 SKILL.md、坏 JSON、错误输出路径/父路径、stdin EOF、不可读候选均有显式处理。对比本地不可读则失败，坏候选跳过告警，无有效候选失败；JSON 模式错误写 stderr。

证据：曾有目标引用仅存在于创建器却通过、空白 description 创建成功后被自身校验拒绝、带标题链接误判、零目标仍打印通过。现有临时目录回归保留这些行为边界。

<a id="safety"></a>
## 安全扫描范围与局部豁免

原 `security-allowlist` 是全文关闭开关，散文提及即可放过危险示例。已改为仅豁免命中同行或紧邻的围栏/缩进代码块；validator 与 comparator 共用扫描函数。

- Markdown 危险管道扫描代码上下文（反引号/波浪线围栏、未闭合围栏、blockquote、≥4 显示列缩进，tab 按 4 列展开）；普通散文与内联规则说明避免误报。代码文件全扫，密钥全文扫。
- 扫描捆绑脚本、references、agents、常见代码后缀及 dotenv/无扩展名凭据文件；下钻隐藏目录，仅跳过 VCS、依赖和缓存噪声。曾被漏掉的 .env、.ssh、.aws 必须可见。
- 凭据模式包括常见 API/token 前缀和 PEM 私钥头；扫描后缀与文档引用支持范围需一起维护。
- 管道右侧识别 shell 执行，处理 launcher/flag/变量赋值、绝对路径、busybox、PowerShell 别名与 CMD；支持 POSIX、PowerShell、CMD 续行及行尾管道。
- 有界归一化处理成对引号、转义、花括号/子壳与 IFS 分隔；保留不成对的 Markdown 收尾反引号。`grep bash`、`command -v bash`、tee/jq 等非执行场景不得误报。

两次修复曾引入回归：无条件合并反引号续行破坏围栏；全局去引号把 docstring 引用变成可执行管道。最终限制为对应词法上下文，并以成品自扫描及良性样本复核。静态扫描不解释 eval、变量二次展开或编码后运行等任意动态语义，这是已接受的覆盖边界。

## 对比评分边界

09-10 从“任意三个目录即可满分”收紧为约定资源类型；09-29 进一步复现：空 scripts/references/templates 仍可将总分 0.76 提到 0.98。现只计含有效文件的资源目录，脚本还需常见脚本扩展名；JSON/text 标明 structural_screening，adoption_verdict 要求任务证据。

结构与元数据分反映本地规范匹配，不能代替领域能力。历史分数维持当时口径；新增采纳结论至少需要同一真实场景的双方产出，无运行条件记录“待任务验证”。短技能不为加分创建空目录；原 0/0.5/1 档未细化，避免无证据地改评分模型。

## 审计收敛依据

09-10—11 的输入形状与安全覆盖修复均进入回归。原记录包含多次“无可复现缺陷”后又发现缺口，压缩时不保留这些绝对完结表述。有效经验：验证修复后行为、检查数据契约和声明一致性，使用同类变体与良性对照。

曾撤销的误报：通用 assets 目录示意可保留；上游未声明 category/risk 的 NULL 不是数据损坏；闭合围栏长度大于开启围栏符合 CommonMark。保留这些否定结论，避免重复“修复”。当前权威检查是回归与 strict；原逐轮测试数量不累计为新的质量承诺。
