# 校验、安全与生成契约

<a id="contracts"></a>
## 09-10—09-12：输入、引用与失败语义

- validate/compare/build/adapt 统一接受 UTF-8 BOM。此前 BOM 会令合法 frontmatter 不被识别，适配器甚至成功退出并原样输出客户端不接受的工具数组。
- 验证器检查 name 类型，避免数字/布尔值触发 traceback；非 AGENT.md 的 Markdown 仅在含 frontmatter 时参与代理发现。链接检查豁免 fenced 示例、剥离合法链接标题并扩展 db/txt/toml 等文件后缀。
- 09-10 移除引用解析向创建器资源目录的回退：被验证代理缺少自身资源就应失败，不能借创建器文件制造假通过。
- **默认行为已替代**：09-10 先修显式空目录失败；09-11 再把默认扫描目标改为 CWD，显式/默认目标均须至少发现一个代理，0 命中退出 1。默认扫描成品根且 0 命中成功的早期行为不再有效。
- description 为空白或超过 300 字符应拒绝；跨行/尖括号提示是 advisory。permission 存在但缺 `"*": deny` 的完整性提示不使 strict 失败；原记录对缺失 permission 的 warning/fail-loud 表述不一致，其强度以现行验证器为准，不借本摘要升级规则。
- color 可缺省；存在时需为 `#RRGGBB` 或受支持主题名。未加引号的 hex 会被 YAML 当注释而变空值，须拒绝。

<a id="security"></a>
## 09-10—09-11：安全覆盖与误报修正

此前 strict 不扫密钥或远程执行管道。新增 `agent_security.py` 并接入定义及捆绑文本扫描，覆盖常见密钥/PEM 私钥头、远程下载后执行；按局部 allowlist 控制已解释的示例，保留围栏与缩进代码识别。

逐轮复现并修正的漏检范围：

| 类别 | 保留下来的判据 |
|---|---|
| shell 别名/包装 | curl/wget 与 PowerShell 下载别名都检查后接执行器；处理 sudo、env、绝对 shell 路径、引号及子壳包装 |
| 续行 | 合并常见续行及行末管道；PowerShell/CMD 续行仅在下一段紧跟管道时合并，避免破坏 Markdown 围栏 |
| 常见混淆 | 有界归一化 IFS、反斜杠、括号包装和 token 内成对引号；保留未成对反引号，避免误伤行内代码 |
| 文件发现 | 扩展无后缀凭据名单，扫描隐藏目录里的私钥/credentials；只跳过 VCS/缓存，不能复用代理定义发现的豁免目录 |

运行期探针确认变体由漏检变检出，隐藏目录凭据从 0 变 2 命中。benign 对照包括 grep、tee、command -v、普通异或字符和非执行式引号引用；“包含 shell 名”本身不构成执行证据。最初无条件续行归一化导致围栏回归，已缩小条件。

**边界**：静态词法扫描不解释 eval、二次展开、base64 或任意运行时混淆。模块直测与验证器端到端测试覆盖已知形态，不承诺安全完备性。

<a id="creation"></a>
## 09-10—09-16：脚手架自洽与路径

- 用安全 YAML 标量写 description；re.sub 使用 lambda 返回替换文本，防止 Windows 路径/正则反斜杠被二次解释、多行内容静默丢失。验证采用真实解析往返；仅比对子串不足。
- mode 只替换字段行，不能误改描述里的 subagent；EOF 有默认/干净退出，输出路径冲突捕获 OSError 并退出 1。旧版 version 前置校验随 09-11 字段移除退役。
- 09-11 真机反馈：`--tools read,grep,glob` 的正文仍列 bash、漏 glob。正文允许/禁止改由同一白名单派生；工具统一小写，显式 edit/write/patch 不再被模板 edit deny 静默覆盖。09-12 权限生成再升级为完整矩阵。
- 09-16 实际产物出现双层同名目录、目标客户端却加载同级扁平文件。默认改为 `<out>/<name>.md`；需要资源目录时显式 `--layout dir` 得 `<out>/<name>/AGENT.md`。out 末级已等于 name、目标已存在均拒绝；校验指向产物父目录。目录形态能力库仍显式选 dir。

## 09-10—09-11：对比工具的证据边界

`agent_compare.py --json` 只输出 JSON，错误走 stderr；缺定义、非映射 frontmatter 不再引发字段访问异常。质量维度与 meta 统一为 **quality7+structure4**，资源组织只计 references/scripts 目录。

候选发现递归支持 AGENT.md 目录和带 frontmatter 的独立 Markdown；排除 README 等说明及已经归入 AGENT.md 的子树，0 候选清晰失败。单改成递归 AGENT.md 会漏掉上游扁平代理，同样不完整。

这些分数属于结构/文本筛查，受本地 schema 偏好影响；不能单凭分差宣称真实任务收益、通用质量或客户端兼容性。
