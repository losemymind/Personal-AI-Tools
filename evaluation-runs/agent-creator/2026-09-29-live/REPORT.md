# agent-creator 真实测评（2026-09-29）

## 结论

实际运行 **OpenCode 1.18.30 / deepseek/deepseek-flash**。计划 17 个运行槽，16 次真正调用模型；无目标技能组生成的角色因颜色不合法，未进入最后一次运行期调用。16 次调用均有本地会话的 provider/model 记录，不是模拟响应；该记录不认证供应商底层权重。

- **触发：8/8**。4 正例成功派发 agent-creator，4 负例未加载，全部完成，无超时或执行错误冒充正确负例。
- **生成与修复**：两任务、三组均完成并保留实际文件；评分汇总见下表，格式合规与运行效果分别报告。
- **生成代理实际调用**：当前版和旧版生成的角色均原生加载并完成审查，各通过 7 项固定判据；无目标技能组适配失败，后续行为不可评估。
- **结论边界**：当前版在这些场景中可完成交付；本次未观察到相对旧版的任务效果提升。单模型、每任务每组一次，不推断普遍优势或稳定提速。

## 设计与复现边界

[协议](protocol.md)、[触发查询](queries.json)、[任务与断言](scenarios.json)、[下游精确提示](runtime.json) 在模型运行前固定，[冻结清单](frozen-inputs.json) 保存输入及当前成品的文件哈希。输入是合成场景，执行为真实模型调用。

三组分别为当前未提交工作树、Git **f68cfc8** 成品、未安装目标技能。两个生成任务分别是：创建只读发布证据审查员；修复权限过宽的缺陷分诊代理并交付 OpenCode/Claude 包。生成阶段只读取对应任务输入，看不到下游测试中的 R17、失败检查和注入材料。

每次调用隔离 cwd、XDG、进程用户目录，使用 --pure，关闭外部插件和 MCP，目标技能之外的技能调用被拒绝。执行前核对 discovery；未修改真实用户安装或配置。两阶段各并发 2，运行时段曾重叠；耗时不作性能基准。

产物审核使用匿名标签，但日志可透露组别，**不是严格盲评**；运行期审核知道组标签。外层独立审核不等于生成模型自己调用了独立评审代理。客观校验对三组使用同一份冻结的当前验证器/适配器，记录为测评者复核。

### 真实发现的交付缺陷

1. 无目标技能组创建角色使用 **color: amber**，超出适配器允许的 hex/语义色；严格校验还缺规范章节标题。内容中的职责等语义仍有覆盖，因此仅按冻结的对应格式条目扣分，不把标题不同判成全部职责缺失。
2. 无目标技能组修复角色写 **permission.default: deny**；原生权限列表将 default 视为普通权限名，继承的全局允许仍在。schema post-check 虽通过，却不满足默认拒绝要求。可解析、可列出代理与权限正确生效是不同结论。
3. 所有原始产物均保留；没有先修正失败组再重跑来替换分数。

## 固定分数之外的缺陷

- 当前与旧版修复任务的 verification 都未经探测就声称环境缺少 OpenCode；实际客户端存在。它们如实记录“未执行原生加载”，没有伪造已经运行的证据，但未执行理由不准确。
- 两组运行期回复都把 release-notes 说成没有版本/构建号；标题已有 **R17 发布标识**，实际缺少的是 build-417 构建号。这是事实措辞错误，7/7 不代表每句话都正确。
- 旧版创建验证记录沿用初稿行数，没有随随后删行更新，属于记录精度问题。
- 无目标技能组修复验证记录把文本提取称为 YAML 解析，并错误解释默认权限；其实际原生加载检查有证据，但自述解释不能替代权限生效检查。

上述观察保留原文及证据，不在看到结果后追加扣分标准。后续改进可针对环境探测与版本标识辨别设计新用例；当前冻结集不能在调参后继续当作未见最终测试。

## 证据与隔离审计

[第二份审计](attempt-1/evidence-audit-v2.json)确认冻结输入/成品、交付物哈希、模型记录和输入完整性有效，配置凭据精确值扫描无匹配。首份审计将原生 prompt 的 CRLF 与文件读取后的 LF 判为差异；仅修正换行表示比较后复核通过，实质字符差异仍会失败。[首份报告](attempt-1/evidence-audit.json)与[纠正说明](attempt-1/audit-review.md)均保留。

15 条需人工确认的观察已逐项核对，未发现读取全局旧创建器或跨组技能的污染。无目标技能组修复任务曾把自己生成的文件复制到**同次隔离 state 下的临时目录**做原生加载检查，超出 cwd 但未进入真实用户安装目录；原始路径、工具 ID 与相同哈希已保留。这说明 cwd/home 隔离不是操作系统沙箱；按事先 B10 范围不把它等同全局安装或外部创建器借用。
